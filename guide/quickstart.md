# 快速开始

本指南将帮助你在 5 分钟内搭建并运行文档站点。

## 前置条件

- Node.js >= 18
- npm、yarn 或 pnpm

## 安装

```bash
# 安装依赖
npm install
```

## 本地开发

```bash
# 启动开发服务器
npm run dev
```

默认在 `http://localhost:5173` 启动，修改文件后自动热更新。

## 构建

```bash
# 生成静态文件到 .vitepress/dist/
npm run build
```

## 预览

```bash
# 本地预览构建结果
npm run preview
```
